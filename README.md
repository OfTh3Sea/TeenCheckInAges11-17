# 🌀 Emotion Wheel
### Adult Emotional Intelligence Tool — Mindscape Suite

> An interactive emotion wheel, mood journal, and guided check-in experience designed for adults who want to understand their emotional life more clearly — and communicate it more honestly.

---

## 📖 Overview

**Emotion Wheel** is a browser-based emotional wellness tool built for adults navigating the full complexity of their inner lives. Drawing from Robert Plutchik's foundational model of human emotion, it offers three ways to explore what you're feeling: an interactive wheel organized by emotion families, a browsable list of the complete emotion vocabulary, and a guided "Find My Feeling" quiz for moments when you're not quite sure what's going on inside.

The tool pairs emotion identification with a private mood journal — so the moment of recognition becomes the beginning of reflection, not the end of it.

Designed for use by **individuals, therapists, counselors, coaches, and mental health practitioners** who want a beautiful, accessible entry point into emotional self-awareness.

## ✨ Features

### 🎡 Three Ways to Find Your Feeling

| Mode | Best For |
|------|----------|
| **Wheel View** | Visual thinkers; exploring emotion families and intensities |
| **Browse All** | People who want to see the full vocabulary laid out |
| **Find My Feeling** | Moments of uncertainty; guided discovery through prompts |

### 🎨 Emotion-Responsive Design
- The entire interface shifts color when an emotion is selected — panel borders, backgrounds, buttons, and navigation all adopt the emotional palette
- Creates a subtle but meaningful visual feedback loop between the emotion named and the environment around you

### 📓 Mood Journal
- Private, persistent journaling linked to each emotional check-in
- After saving a journal entry, the flow returns naturally to the wheel for the next check-in
- Built on `localStorage` — everything stays on your device, private by default

### 🔁 Linked Check-in Cycle
- The tool is designed as a loop, not a one-time interaction
- Each session flows: identify → reflect → journal → return
- Supports daily practice and pattern awareness over time

### 📊 Plutchik Emotion Framework
- Organized around Plutchik's eight primary emotion families: joy, trust, fear, surprise, sadness, disgust, anger, anticipation
- Includes secondary and tertiary emotions at varying intensities
- Language calibrated for adult emotional complexity

## 🚀 Getting Started

### Requirements
- Any modern browser (Chrome, Safari, Firefox, Edge)
- No installation, server, or accounts required
- Works offline after initial load

### Installation

```bash
git clone https://github.com/OfTh3Sea/emotion-wheel.git
cd emotion-wheel
open therapy-suite.html
```

Or download `therapy-suite.html` and open it directly in any browser.

## 💾 Privacy

- All journal data is stored locally in your browser via `localStorage`
- No data is ever sent to a server
- No accounts, logins, or tracking of any kind
- Clearing your browser's site data will erase saved journal entries
